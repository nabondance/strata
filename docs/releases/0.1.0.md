# Strata 0.1.0 — release candidate

Strata turns the Git history of Claude Code and Codex configuration into a single offline HTML report. The report shows stored instruction tokens over time, a category treemap, revision comparisons, changed files, and a searchable inventory. The CLI can also write schema-version-5 JSON, create a shareable export with aliased identifiers, and print or install a skill that helps coding agents interpret it. Skill manifests and their supporting resources are grouped while resource bytes remain separate from instruction-token measurements.

The analysis reads tracked Git blobs on a first-parent timeline without modifying the target repository. It does not include source text in default HTML or JSON output. The default token measure is a consistent UTF-8-byte estimate. Optional local OpenAI `cl100k_base` and `o200k_base` encoding modes count stored text under those encodings; neither establishes actual context loaded in a session or Claude/Gemini token counts. Structured configuration and supporting resources are listed by source bytes only.

The opt-in composite GitHub Action and `strata diff` command compare two full commits and summarize configuration deltas without posting a PR comment. The Action writes a job summary when explicitly included in a workflow.

After publication, run `npx context-strata analyze . --output report.html` or install the package and use `strata analyze .`. Node.js 22.13 or newer is required. This candidate has been tested on Node 22 and Node 24 before publication.

Known limits: only documented Claude Code and Codex paths are classified; shallow clones omit earlier history; comparisons match files by provider, category, and path; moved instructions may appear as removal and addition; reports expose file paths and commit metadata even though source text is excluded.
