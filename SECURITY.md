# Security policy

Strata is in early development. Security fixes are considered for the current `main` branch; no released versions or response-time guarantee exist yet.

To report a vulnerability, use [GitHub's private vulnerability reporting page](https://github.com/nabondance/strata/security/advisories/new) if it is available to you. If that path is unavailable, open an issue requesting a private contact channel **without posting exploit details, credentials, or private repository content**. The maintainer can then arrange a private exchange.

When reporting, describe the affected version or commit, reproduction steps, and impact. Please give the maintainer time to investigate before public disclosure.
