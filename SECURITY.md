# Security policy

Strata is in early development. Security fixes are considered for the current `main` branch only. There is no guaranteed response time yet.

To report a vulnerability:

1. Use [GitHub's private vulnerability reporting page](https://github.com/nabondance/strata/security/advisories/new) if it is available to you.
2. If it is not, open an issue that asks for a private contact channel, **without posting exploit details, credentials, or private repository content**. The maintainer can then arrange a private exchange.

In your report, describe the affected version or commit, the steps to reproduce the problem, and its impact. Please give the maintainer time to investigate before disclosing it publicly.
